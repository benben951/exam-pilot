# 数学二章节级里程碑

> 规则：星级以知能行实际显示为准。当前章节星级未完整汇报前保持“待校准”，不把月度目标当成已完成事实。

## 章节目标矩阵

| 阶段 | 高数 | 线代 | 过关标准 |
|---|---|---|---|
| 第一轮基础 | 极限与连续、一元微分、一元积分、多元微分、微分方程 | 行列式/矩阵、向量组/方程组、特征值/二次型 | 每个知能行章节/专题达到3星；记录首次正确率和主要错因 |
| 滚动巩固 | 已达3星章节按复习队列回忆 | 已达3星章节按复习队列回忆 | 48小时、7天后抽检；忘记或正确率下降则回到专题训练 |
| 第二轮提升 | 全部首轮3星后按薄弱章节二刷 | 全部首轮3星后按薄弱章节二刷 | 不追求重复刷满，重点处理概念、条件、方法和计算错误 |
| 真题/预测卷 | 10月起逐步进入 | 10月起逐步进入 | 套卷失分必须映射回知能行章节 |

## 当前到10月的推进逻辑

### 8月剩余

- 主线：继续当前知能行专题，先把当前专题推到3星。
- 复习：每天结束前回忆一个已经训练过的旧知识点，10-15分钟即可。
- 不要求现在完成高数整套二刷，也不要求同时把线代和高数都推到末尾。

### 9月

- 主线：完成高数剩余专题并启动/推进线代。
- 复习：采用“新专题80% + 旧专题20%”的滚动结构。
- 月末目标：已覆盖章节尽量达到3星；未达到3星的章节列为10月优先补强项。

### 10月

- 主线：从知能行章节训练切换到李艳芳、超越等数二预测卷/模块测。
- 回炉：每套卷的失分必须标注到对应章节和错因。
- 不做：没有掌握范围就盲目完整二刷所有章节。

## 何时算“进入二轮”

满足以下条件才进入系统二轮：

1. 高数和线代所有数二范围章节都至少完成一次训练；
2. 每章至少有一次知能行星级记录；
3. 低于3星的章节已列出具体原因；
4. 至少完成一次不依赖提示的模块抽检。

在此之前，所谓“二刷”只指滚动回忆，不是重新通读整章。

## 数二范围

只覆盖：极限与连续、一元微积分、多元微分、微分方程、行列式、矩阵、向量组/线性方程组、特征值/二次型。无穷级数、概率统计、空间解析几何、三重积分、曲线曲面积分不进入本计划。

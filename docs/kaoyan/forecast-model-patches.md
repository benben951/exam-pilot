# 预测与调度补丁

## 不可变红线

动态调度只能改变顺序、分钟和复习方式，不能静默删除核心章节。红线清单见 `data/immutable-targets.json`。383分与55/55/90/90是2026历史参考，不是2027官方线。

## 滚动校准与阻尼

前3个真实记录日只用于校准启动；达到至少3个记录日后，优先使用滚动21天完成率。新计划相对上一已保存计划的总分钟默认限制在±20%，避免短期峰值导致长期任务震荡。

## 概率分层

第一次整科或阶段测评若标记`role: baseline`，只用于发现缺口，不进入概率。正式概率报告需区分：

```text
总分线通过率
各科单科线通过率
总分且单科同时通过率
瓶颈科目
```

复试模型未完成校准前，仍不输出最终录取概率。

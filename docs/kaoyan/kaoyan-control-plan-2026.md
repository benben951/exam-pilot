# 2027北大软微金科考研当前执行版

> 更新：2026-08-25
> 
> 数字目标唯一来源：`data/monthly-targets.json`。每日任务由 `.scripts/study_cycle.py` 生成。本文覆盖旧规划中的冲突口径。

## 总原则

```text
工作稳定性优先
→ 数学和831是主得分引擎
→ 英语保持真题与词汇连续性
→ ACP在9月23日前独立占用午间/周末
→ 政治10月15日启动
→ 录取概率只认合格留出测评
```

## 阶段任务

### 现在至8月31日：校准与基础重建

- 数学：只用知能行，记录专题、星级、有效分钟和主要卡点；不安排纸质刷题。
- 831：完成基础重建，先建立函数、边际、导数、偏导、拉格朗日和消费者/生产者最小模型；主线先学尼科尔森微观、再学曼昆宏观，学长题集作为主练习；不能独立理解时不进入压缩错题集。
- 英语：不背单词；2003年起真题阅读每周4篇，完成定位、同义替换、陷阱和关键生词复盘。
- 政治：不占主学习时段。
- ACP：从8月23日起，工作日午间35分钟，周六120分钟；先答题再看解析，记录题数、正确数、蒙对数和薄弱点。

### 9月1日至9月22日：首轮覆盖与ACP冲刺

- 数学：知能行继续推进高数、线代专题，目标是10月前各章3星，不因赶进度切换多套资料。
- 831：按“尼科尔森章节学习 → 学长题集 → 闭卷复做 → 曼昆宏观章节学习 → 学长题集”推进；数理经济学、就酱背经济、B站扫盲和Codex只处理具体不懂点，不并行通读。
- 英语：阅读保持每周4篇，加入完形；2022-2026整套真题继续留作后期测评。
- ACP：周末逐步改为限时模拟；9月22日只回顾错题和考试材料。
- 9月23日：ACP考试，只做证件、时间、地点、交通核验。

### 9月24日至10月14日：数学/831/英语过渡

- 数学：完成知能行3星缺口，准备进入预测卷。
- 831：完成宏观模型首轮，开始阶段闭卷输出。
- 英语：阅读、完形继续；准备10月新题型和翻译。
- 政治：仍不正式占用主学习时段，只确认资料和时政记录口径。

### 10月15日至10月31日：真题一轮与政治启动

- 数学：李艳芳等数学二预测卷/超越卷，按失分回到知能行对应专题。
- 831：18-25真题第一轮，记录空白题、模型缺口和完整作答情况。
- 英语：阅读、完形、新题型、翻译并行，近年整卷继续留出。
- 政治：每天约30分钟，基础框架、选择题和权威时政专题同步启动；不追零散新闻。

### 11月：真题二轮与主观题表达

- 数学：真题/模拟卷、错题回炉和提速。
- 831：真题二轮、背诵手册、闭卷大题和论述提纲。
- 英语：小三门保持，启动大小作文输出；保护近年留出整卷。
- 政治：选择题、时政专题、主观题框架；肖八等只作检测和查漏，不当押题答案。

### 12月：冲刺与整卷模拟

- 数学：错题规则、整卷手感和时间分配。
- 831：真题三刷、背诵手册、闭卷输出。
- 英语：2022-2026留出真题整卷模拟、作文定型。
- 政治：多源冲刺材料、时政覆盖、主观题输出和选择题回炉。

## 每日最低动作

### 工作日

1. 数学：按任务卡完成知能行核心块。
2. ACP考前：午间35分钟题库；考后取消。
3. 英语：词汇20分钟；任务卡指定日完成真题阅读。
4. 831：按任务卡完成模型/例题/闭卷输出。
5. 23:00前：汇报真实分钟、产出、结果、阻塞和睡眠。

### 周末

- 数学大块训练。
- 831专题与闭卷抽检。
- ACP考前周六120分钟专项。
- 周日完成周复盘和下一周三项优先级。

## 公司白天泛听

只听已学习过的ACP解析、已精读英语真题TTS、已学831概念口播或词汇例句。新数学推导、新831模型和未精读英语不作为背景音。泛听不计有效学习分钟和录取概率。

## 验收与概率边界

- 过程验收：知能行星级、首次题目正确率、831模型卡、英语题型复盘、ACP模块正确率。
- 能力验收：闭卷模型卡、阶段测、整科首次限时测评。
- 录取概率：只使用首次、严格限时、事先注册、留出的可比整科测评；无数据时写“数据不足，无法判断”。

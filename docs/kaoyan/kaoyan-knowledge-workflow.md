# 考研知识编译与学习工作流

## 一句话

把原始资料编译成可复用知识，把知识变成可验收学习动作，再用真实测评更新风险；不把大模型回答直接当成知识或分数。

## 六步闭环

1. **Raw摄取**：保存PDF、可搜索OCR、公众号原文和题目证据。
2. **Wiki编译**：按数学、英语、831、政治和考研策略提炼概念、模型、规则和边界。
3. **Query查询**：临时回答、比较和计划写入输出区，不自动污染Wiki。
4. **Codex综合**：跨来源比较，标出一致、冲突、过期和待核验结论。
5. **Promote回流**：只有有来源、适用条件和复核动作的结论才进入长期Wiki。
6. **Lint维护**：检查重复、孤立、无来源、过期政策和把过程数据误当成绩的情况。

## 每次学习的最小闭环

```text
资料片段 → 自己尝试 → 错误诊断 → 一条规则/一张模型卡 → 闭卷复测 → 复习队列
```

## 适合本项目的输出对象

| 对象 | 存放 | 作用 |
|---|---|---|
| 原文/扫描/OCR | `raw/` | 保留证据 |
| 概念与模型 | `知识库/`、`professional-course/` | 可复用理解 |
| 错题规则 | `mistakes/` | 纠正错误模式 |
| 831模型卡 | `professional-course/`、`anki/` | 闭卷输出 |
| 临时回答 | `output/`或会话 | 不污染长期知识 |
| 进度和测评 | `data/` | 计算过程风险和录取概率 |

## 绝不混淆

- 经验贴不是招生公告。
- 培训机构宣传不是考试事实。
- 看懂答案不是独立掌握。
- 知能行星级不是数学考试分数。
- 学习时长不是录取概率。
- AI生成题不进入正式留出测评。
